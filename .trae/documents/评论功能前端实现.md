# 评论功能前端实现计划

## Context 背景

后端 mall（mall-portal 模块）已实现商品评论功能与 OSS 直传，但前端 mall-app-web 尚未对接：

- 商品详情页 `product.vue` 的"评价"区块是静态假数据（[product.vue L97-L122](file:///c:/Users/33383/Desktop/code/mycode/github/mall-app-web/src/pages/product/product.vue#L97-L122)）
- 订单列表 `order.vue`、订单详情 `orderDetail.vue` 的"评价商品"按钮无点击事件
- 个人中心 `user.vue` 的"我的评价"菜单无跳转

目标：前端对接评论接口，实现 **商品详情评价列表（含分页、点赞、回复）、发表评价（含 OSS 晒图）、我的评价列表** 三个完整闭环。

## 后端接口（已确认）

| 接口 | 说明 |
| --- | --- |
| `GET /comment/list?productId&pageNum&pageSize` | 商品评论分页，返回 `CommonPage<PmsCommentDetail>` |
| `GET /comment/my?pageNum&pageSize` | 我的评价分页（需登录），返回同结构 |
| `POST /comment/add` body `{productId, star, content, pics, productAttribute}` | 发表评价，需购买资格 |
| `POST /comment/replay/add` body `{commentId, content}` | 回复评论 |
| `POST /comment/like/{id}` | 点赞评论 |
| `GET /aliyun/oss/policy` | OSS 前端直传签名 `{accessKeyId, policy, signature, dir, host, callback}` |

**PmsCommentDetail 字段**：`id, productId, productName, memberNickName, memberIcon, star(0-5), content, pics(逗号分隔URL), productAttribute, createTime(ISO串), collectCouont(点赞数), readCount, replayCount, replayList[]`
**replayList 项**：`id, commentId, memberNickName, memberIcon, content, createTime, type(0会员/1管理员)`

**OSS 直传流程**：取 policy → 本地生成文件名 `dir/时间戳-随机数.扩展名` → 表单字段 `{key, policy, OSSAccessKeyId, signature, success_action_status:'200'}` + `file` 上传到 `host` → 图片 URL = `host + '/' + key`。

## 关键实现要点

### 1. 商品详情页评价区块（product.vue）

- 新增状态：`commentList: PmsCommentDetail[]`、`commentPage/pageNum/pageSize`、`loadingType`、`commentTotal`。
- `onLoad` 拿 `productId` 后并行加载 `getCommentListAPI`；`scrolltolower` 时 `uni-load-more` 分页加载更多。
- 每条评论卡片渲染：头像（`memberIcon || '/static/missing-face.png'`）、昵称、`uni-rate` 只读星级（`:value="item.star" :disabled="true" :size="12"`）、内容、晒图九宫格（`pics.split(',')`）、规格 `productAttribute`、时间（复用 `formatDate`）、点赞数 `collectCouont`、回复数 `replayCount`。
- 头部"评价(N)"显示 `commentTotal`，好评率 = `star>=4 条数/总数`。
- **点赞**：点击调 `likeCommentAPI(id)` 后本地 `collectCouont+1`（后端无防重复，前端简单处理即可）。
- **回复**：点击评论卡片"回复"→ 弹输入层（`uni.showModal` editable 或自定义底部弹层）→ `replyCommentAPI({commentId, content})` → 成功刷新该页评论。
- 已登录校验：`http.ts` 已自动处理 401 跳登录，无需额外处理。

### 2. 发表评价页（evaluate.vue）

- **入参**：订单入口跳转时用 `uni.navigateTo` + query 传 `productId, productName, productPic, productAttribute`（`encodeURIComponent` 编码），`onLoad` 解析。订单列表/详情取 `orderItemList` 第一项传参（后端按订单整体标记 `commentTime`，一单一次评价）。
- **UI**：顶部商品卡片（图/名/规格）→ `uni-rate` 可点选星级（1-5）→ `textarea` 内容（限 500 字）→ 晒图区（`uni.chooseImage` 最多 9 张，逐张 `uploadImageToOSS` 上传，缩略图可删除）→ 底部提交按钮。
- **提交**：校验 `star>=1`、`content` 非空；`pics` 用逗号拼接；调 `addCommentAPI` → 成功 toast → `uni.navigateBack()`（订单页 `onShow` 刷新）。

### 3. 订单入口 + 已评价隐藏

- `order.vue` L73、`orderDetail.vue` L118：`@click="navToEvaluate(item)"`，取 `item.orderItemList[0]` 的 `productId/productName/productPic/productAttr`（`productAttr` 原样传入作 `productAttribute`）。
- `OmsOrderDetail` 类型（[order.d.ts](file:///c:/Users/33383/Desktop/code/mycode/github/mall-app-web/src/types/order.d.ts)）追加可选字段 `commentTime?: string`；订单列表/详情对 `status===3 && commentTime` 为空才显示"评价商品"按钮。

### 4. 我的评价页（myComment.vue）

- 仿 `readHistory.vue` 分页模式：`onLoad` + `scrolltolower` 加载 `getMyCommentListAPI`，`enablePullDownRefresh` 下拉刷新。
- 评论卡片展示同商品详情页样式（星级/内容/晒图/回复数），点击卡片 `navigateTo` 商品详情页。

### 5. OSS 直传注意点

- `http.ts` 拦截器会为 `uploadFile` 附加 `source-client`/`Authorization` 头并强制 10s 超时；OSS 直传不依赖这些头可正常工作，上传稍大图片可能超时。建议将拦截器超时改为 `options.timeout = options.timeout || 10 * 1000`（仅一行，`http.ts` L20）。
- 需后端 `aliyun.oss.*` 配置可用（用户已引入 OSS）。

## 验证方式

1. 启动后端（localhost:8085），前端 `npm run dev:h5`（或 dev:mp-weixin）。
2. 商品详情页：评论区块显示真实评论、头像/星级/晒图/回复列表正确；滚动加载更多；点赞数+1；回复后列表刷新。
3. 未登录访问：点赞/回复/我的评价触发 401 自动跳登录。
4. 用已完成订单：点"评价商品"进评价页 → 选星、填内容、传图（OSS 直传成功拿到 URL）→ 提交成功返回 → 该订单"评价商品"按钮消失（commentTime 已标记）。
5. 个人中心"我的评价"：显示已发表评论列表，点击跳商品详情。
