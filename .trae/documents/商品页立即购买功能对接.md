# 商品页"立即购买"功能对接

## Context（背景）

后端（`C:\Users\33383\Desktop\code\mycode\github\mall`，mall-portal 模块）已实现"在商品页直接购买并生成订单"能力，新增两个接口：

- `POST /order/generateBuyNowConfirmOrder`：请求体 `{ productSkuId, quantity }`，返回 `ConfirmOrderResult`（与购物车确认单结构一致）
- `POST /order/generateBuyNowOrder`：请求体 `OrderParam + { productSkuId, quantity }`（即 `memberReceiveAddressId / couponId / useIntegration / payType / productSkuId / quantity`），返回 `{ order, orderItemsList }`

前端（mall-app-web）商品详情页 [product.vue](file:///c:/Users/33383/Desktop/code/mycode/github/mall-app-web/src/pages/product/product.vue) 的"立即购买"按钮目前只是占位提示 `暂时只支持从购物车下单！`，[order.ts](file:///c:/Users/33383/Desktop/code/mycode/github/mall-app-web/src/apis/order.ts) 也没有立即购买相关 API。

本次目标：前端对接这两个接口，实现"商品页选规格/数量 → 确认订单页 → 生成订单"完整链路。

**已确认的需求决策：**
1. 复用现有确认订单页 [createOrder.vue](file:///c:/Users/33383/Desktop/code/mycode/github/mall-app-web/src/pages/order/createOrder.vue)，为其增加"立即购买"模式，不新建页面
2. 在商品页规格弹窗中增加数量选择器（复用现有组件 `uni-number-box`，[cart.vue](file:///c:/Users/33383/Desktop/code/mycode/github/mall-app-web/src/pages/cart/cart.vue) 已有使用先例）

## 改动清单

### 1. `src/types/order.d.ts` — 新增类型

在 `OrderParam` 之后新增：

```ts
/** 立即购买生成确认单请求参数 */
export type BuyNowConfirmParam = {
  /** 商品SKU ID */
  productSkuId: number
  /** 购买数量 */
  quantity: number
}

/** 立即购买生成订单请求参数（对应后端 BuyNowParam，继承 OrderParam） */
export type BuyNowParam = Omit<OrderParam, 'cartIds'> & {
  /** 商品SKU ID */
  productSkuId: number
  /** 购买数量 */
  quantity: number
}
```

### 2. `src/apis/order.ts` — 新增 2 个 API

```ts
/** 根据立即购买信息生成确认单 */
export const generateBuyNowConfirmOrderAPI = (data: BuyNowConfirmParam) => {
  return http<ConfirmOrderResult>({
    method: 'POST',
    url: '/order/generateBuyNowConfirmOrder',
    data,
  })
}

/** 根据立即购买信息生成订单 */
export const generateBuyNowOrderAPI = (data: BuyNowParam) => {
  return http<GenerateOrderResult>({
    method: 'POST',
    url: '/order/generateBuyNowOrder',
    data,
  })
}
```

并补充对应类型 import。

### 3. `src/pages/product/product.vue` — 规格弹窗加数量选择器 + 立即购买逻辑

- 引入 `uniNumberBox from '@/components/uni-number-box.vue'`
- 新增状态：
  - `buyQuantity = ref(1)`：立即购买数量
  - `specAction = ref<'buy' | ''>('')`：记录规格弹窗本次打开的目的（'buy' 表示选完规格数量后立即购买），关闭时重置
- 规格弹窗（`.attr-content`）在规格选择下方新增"数量"行，使用 `uni-number-box`：
  - `:min="1"`、`:max="product.stock"`、`:value="buyQuantity"`，`@eventChange` 更新 `buyQuantity`
- 弹窗底部"完成"按钮改为调用 `handleSpecConfirm`：
  - `specAction === 'buy'` → 执行立即购买校验与跳转，成功后关闭弹窗
  - 否则仅关闭弹窗（保持原"完成"行为）
- 改造 `handleBuy`：
  1. 未登录 → 复用 `handleCheckLogin()`
  2. 打开规格弹窗，设置 `specAction = 'buy'`（让用户确认规格与数量）
- 新增 `handleBuyNow()`（由弹窗确认时调用）：
  1. `getSkuStock()` 为空 → 提示"请选择规格"，留在弹窗
  2. 校验 `buyQuantity`（1 ~ 库存）
  3. `uni.navigateTo({ url: \`/pages/order/createOrder?skuId=${sku.id}&quantity=${buyQuantity}\` })`
  4. 关闭规格弹窗（`specClass = 'none'`）、重置 `specAction`、重置 `buyQuantity = 1`

> 注：`handleAddToCart` 保持现有逻辑不变（数量固定 1）。

### 4. `src/pages/order/createOrder.vue` — 支持"立即购买"模式

- 新增状态：
  - `mode = ref<'cart' | 'buyNow'>('cart')`
  - `productSkuId = ref<number | null>(null)`
  - `quantity = ref(1)`
- `onLoad` 解析参数：
  - 存在 `option.skuId` → `mode = 'buyNow'`，记录 `productSkuId`、`quantity`
  - 存在 `option.cartIds` → 保持现有购物车模式
- `loadData` 按模式分流：
  - buyNow：`generateBuyNowConfirmOrderAPI({ productSkuId, quantity })`
  - cart：现有 `generateConfirmOrderAPI(cartIds)`
  - 返回结构均为 `ConfirmOrderResult`，后续赋值逻辑不变
- `handleSubmit` 按模式分流：
  - buyNow：`generateBuyNowOrderAPI({ payType, couponId, memberReceiveAddressId, useIntegration, productSkuId, quantity })`
  - cart：现有 `generateOrderAPI(orderParam)`
  - 成功后提示"是否立即支付"逻辑保持不变

## 关键复用点

- `generateConfirmOrder` / `generateOrder` 的返回结构 `ConfirmOrderResult` / `GenerateOrderResult` 已在 [order.d.ts](file:///c:/Users/33383/Desktop/code/mycode/github/mall-app-web/src/types/order.d.ts) 定义，立即购买接口返回结构完全相同，直接复用
- 数量组件复用 `uni-number-box.vue`
- 登录校验复用现有 `handleCheckLogin()`
- 支付跳转链路（`/pages/money/pay?orderId=`）不变

## 验证方式

1. 启动后端（localhost:8085，需含最新 buy-now 接口）
2. 前端 `npm run dev:h5` 启动 H5 开发服务
3. 浏览器走查流程：
   - 未登录点"立即购买" → 弹出登录引导
   - 登录后进入商品详情 → 点"立即购买" → 规格弹窗出现，可选规格、可加减数量（上限为库存）
   - 确认后跳转确认订单页，商品/金额信息正确（走 `generateBuyNowConfirmOrder`）
   - 提交订单 → 提示去支付 → 跳转支付页 → 支付成功
4. 回归：购物车"去结算"→ 确认订单 → 提交，仍走 `generateConfirmOrder` / `generateOrder` 正常
